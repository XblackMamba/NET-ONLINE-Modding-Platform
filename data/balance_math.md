# Все ключевые математические формулы движка **X-Ray (S.T.A.L.K.E.R.)**, адаптированные под PvP-систему мультиплеера.

### 1. Проверка на пробитие брони

Первое, что делает движок при попадании пули в кость персонажа — сравнивает пробивную способность патрона с классом защиты брони для этой конкретной кости.

$$\text{Сравнение: } \mathbf{k\_ap} \quad \text{против} \quad \mathbf{Armor_{bone}}$$

* **Условие пробития:** Если $k\_ap \ge Armor_{bone}$ — броня **пробита**. Урон рассчитывается по **Формуле №2** (без порезки костюмом).
* **Условие непробития:** Если $k\_ap < Armor_{bone}$ — броня **НЕ пробита**. Включается заброневая травма, урон рассчитывается по **Формуле №3**.

*В конфиге Экзоскелета:* $Armor_{bone} = \mathbf{0.4050}$ (для всех костей).

---

### 2. Формула №2: Урон при ПРОБИТИИ брони (Полный урон)

Применяется, если пуля пробила плиту бронежилета, либо если на цели вообще нет брони.

$$\text{Итоговый урон (ХП)} = \mathbf{hit\_power} \times \mathbf{k\_hit} \times \mathbf{Scale_{bone}} \times \mathbf{Immunity}$$

* $\mathbf{hit\_power}$ — базовый урон оружия из его конфига (например, `wpn_ak74/base.ltx`). По умолчанию мы принимаем его за $1.0$.
* $\mathbf{k\_hit}$ — базовый урон патрона из `weapons.ltx`.
* $\mathbf{Scale_{bone}}$ — множитель урона при попадании в конкретную кость (прописан в `damages.ltx` первым числом). В твоем конфиге для всех костей он равен **`1.0`** (то есть урон не срезается).
* $\mathbf{Immunity}$ — базовая восприимчивость актора к огнестрельному урону из `mp_actor.ltx` (в мультиплеере всегда равна **`0.5`**).

#### 📝 Пример расчета (5.45 AP против Экзоскелета в грудь):

* $hit\_power = 1.0$ (АК-74)
* $k\_hit = 0.56$ (Патрон 5.45 AP)
* $Scale_{bone} = 1.0$ (`bip01_spine` для Экзоскелета)
* $Immunity = 0.5$ (множитель воспримчивости)
* *Поскольку патрон AP ($k\_ap = 0.65$) пробивает Экзоскелет ($0.4050$), считаем:*

$$\text{Урон} = 1.0 \times 0.56 \times 1.0 \times 0.5 = \mathbf{0.28} \text{ (28\% ХП за выстрел)}$$

$$\text{ТТК в грудь} = 100\% / 28\% \approx \mathbf{3.57} \rightarrow \mathbf{4 \text{ пули}} \text{ (или 3 пули, если у цели уже было чуть меньше ХП)}$$

---

### 3. Формула №3: Урон при НЕПРОБИТИИ брони (Заброневая травма)

Применяется, когда броня заблокировала пулю. Урон по персонажу наносится только за счет кинетического удара (контузии).

$$\text{Итоговый урон (ХП)} = \left( \mathbf{hit\_power} \times \mathbf{k\_hit} \times \mathbf{Scale_{bone}} \times \mathbf{Immunity} \right) \times \mathbf{hit\_fraction\_actor}$$

* $\mathbf{hit\_fraction\_actor}$ — коэффициент заброневой травмы из конфига костюма.
* *Для твоего Экзоскелета:* $hit\_fraction\_actor = \mathbf{0.25}$ (то есть за бронеплиту проходит только 25% от полного урона пули).

#### 📝 Пример расчета (5.45 FMJ против Экзоскелета в грудь):

* $hit\_power = 1.0$
* $k\_hit = 0.58$
* $Scale_{bone} = 1.0$
* $Immunity = 0.5$
* *Поскольку патрон FMJ ($k\_ap = 0.38$) НЕ пробивает Экзоскелет ($0.4050$), урон умножается на заброневой коэффициент костюма ($0.25$):*

$$\text{Урон} = (1.0 \times 0.58 \times 1.0 \times 0.5) \times 0.25 = 0.29 \times 0.25 = \mathbf{0.0725} \text{ (7.25\% ХП за выстрел)}$$

$$\text{ТТК в грудь} = 100\% / 7.25\% \approx \mathbf{13.7} \rightarrow \mathbf{14 \text{ пуль для убийства}}$$

---

### 4. Мультипликаторы урона по зонам тела (Hit-box)

Чтобы рассчитать попадание в другие части тела, итоговый урон из Формулы №2 или №3 нужно дополнительно умножить на коэффициент уязвимости зоны из `mp_actor.ltx` (секция `[actor_damage]`):

$$\text{Финальный урон} = \text{Итоговый урон из Формулы (2 или 3)} \times \mathbf{Zone\_Multiplier}$$

Стандартные значения $\mathbf{Zone\_Multiplier}$ для СТАЛКЕРа (если они не менялись):

* **Голова** (`bip01_head`): **$\times 6.0$** (смертельная зона)
* **Грудь / Спина** (`bip01_spine`): **$\times 1.2$**
* **Живот / Таз** (`bip01_pelvis`): **$\times 2.7$** (очень уязвимая зона)
* **Руки / Ноги** (`bip01_l_upperarm`, `bip01_l_thigh`): **$\times 0.3$** (зона минимального урона)

#### 📝 Пример расчета (Ваншот Жеканом в шлем Экзоскелета):

* $hit\_power = 1.0$
* $k\_hit = 0.75$ (Патрон Жекан)
* $k\_ap = 0.96$ (Пробивает шлем $0.4050 \rightarrow$ считаем по Формуле №2)
* $Scale_{bone} = 1.0$
* $Immunity = 0.5$
* $Zone\_Multiplier_{\text{head}} = 6.0$

$$\text{Урон в голову} = (1.0 \times 0.75 \times 1.0 \times 0.5) \times 6.0 = 0.375 \times 6.0 = \mathbf{2.25 \text{ (225\% ХП)}}$$


*Результат:* Гарантированная смерть с первого выстрела (225% урона при 100% максимального здоровья).

Используя эти четыре математические модели, ты сможешь легко рассчитывать и настраивать ТТК для абсолютно любого калибра и оружия.
